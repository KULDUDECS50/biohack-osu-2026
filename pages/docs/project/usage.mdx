# Usage & Setup

## Installation

<Steps>

### Clone the repository

```bash
git clone <repo-url>
cd BioHack
```

### Create virtual environment

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

</Steps>

## Running the Pipeline

### Full pipeline (recommended)

Run everything end-to-end:

```bash
python main.py --n-donors 5000 --n-recipients 3000
```

This generates data, trains the model, runs both allocation strategies, and outputs evaluation metrics and plots.

### Step by step

Run each component individually:

```bash
# 1. Generate synthetic data
python data_generator.py --n-donors 5000 --n-recipients 3000

# 2. Engineer features
python feature_engineering.py

# 3. Train model
python model_training.py

# 4. Run allocation simulation
python allocation_simulator.py

# 5. Generate evaluation report
python evaluation.py
```

## Outputs

After running the pipeline, you'll find:

| Output | Location | Description |
|--------|----------|-------------|
| Trained model | `models/` | Serialized XGBoost model file |
| Discard rate chart | `outputs/plots/` | Traditional vs. ML discard comparison |
| ROC curve | `outputs/plots/` | Model discrimination performance |
| Fairness plots | `outputs/plots/` | Distribution across priority groups |
| Metrics report | `outputs/reports/` | Full evaluation summary (JSON + text) |

<Callout>
The default parameters (5,000 donors, 3,000 recipients) balance statistical significance with reasonable runtime. Increase for more robust results; decrease for faster iteration.
</Callout>
